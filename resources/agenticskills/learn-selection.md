# Learning note: methods, access, and context

Reference: https://agenticskills.io/learn/skills-vs-mcp-servers (read 2026-11-09). This is an original D_AI note, not a redistributed article. No blanket license is inferred from the directory.

- A skill supplies working instructions; a tool performs an operation; MCP exposes operations/resources over a protocol; a workflow links roles, inputs, checks and outputs.
- Select according to the missing capability, not download counts. Reuse native tools rather than adding another model runtime or duplicate memory database.
- Correct the article's simplified risk framing: skills can include executable scripts and malicious instructions. MCP can be local and offline; neither transport nor plain text establishes safety.
- Search short metadata first. Load only the necessary resource page or section. Native compaction keeps a free context buffer, while durable state keeps goals, decisions, waits and source references recoverable.
- Output byte limits are measurable; token counts depend on the model tokenizer. Do not claim a percentage cost/quality improvement without a representative baseline.

Exercise: for a document review, separately identify conversion access, review method, evidence lineage and final acceptance. Installing a converter supplies only the first item.
