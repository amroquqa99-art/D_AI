# Glucose measurements

All values in `measurements.csv` are in **mg/dL**.

The laboratory reports in mg/dL. When a result is required in **mmol/L**,
use the factor **0.0555** (1 mg/dL = 0.0555 mmol/L), that is: multiply the
mg/dL value by 0.0555.

Rows where `fasting` is `no` are post-meal samples and are excluded from any
fasting average.
