# نظام الاستثمار وتحليل الفرص

Primary: `dai-investor`. الحالة: LIVE_SLICE_LIMITED. أولوية تشغيل ثالثة. مرجع التكامل: [المعمارية](../TARGET_ARCHITECTURE.md).

## الأهداف

بحث الأسواق والشركات والأصول والفرص ومقايضاتها، مع تفسير أدلة ومخاطر وسيناريوهات واختبار أطروحات. مستقل عن المستشار المالي الشخصي الذي يدير مال المالك ودخله والتزاماته، ويتعاون معه.

## القدرات التفصيلية

- تحديد universe الاستثمار والأفق والقيود ومعايير الفرصة ونقص البيانات.
- قراءة قوائم وإفصاحات وحوكمة وإدارة ونشاط تجاري ومنافسين وقطاع وسلسلة توريد.
- تحليل اقتصاد كلي وأسواق وسيولة وتقلبات وارتباطات وتسعير وقيود تنفيذ عند توفر البيانات.
- تقييم مالي وسيناريوهات حساسية، مع فصل الأرقام المنشورة عن تقديرات النموذج.
- تحليل عوامل تقنية وسلوكية وجغرافية وتنظيمية ذات أثر على الأطروحة، دون اعتبار خبر منفرد دليلًا كافيًا.
- مقارنة فرص وتكوين أطروحات مؤرخة وشروط بطلانها، ورأي معاكس مستقل.
- تحليل محفظة ومخاطر وتركيز وسيولة وتعرض وسيناريو ضغط.
- Backtesting ومحفظة ورقية ومتابعة أداء وقرارات على مدى طويل، مع سياسة تحديث مصادر.

## الأدوار المتخصصة

محلل إفصاحات ومحاسبة، متخصص قطاع/اقتصاد، محلل كمي وسوق، محلل تقنية وسلسلة توريد، محلل سلوك، مصمم سيناريوهات وتقييم، مدير مخاطر محفظة، مراجع أطروحة، ومدقق بيانات. التخصصات تنمو وفق الأصول المستخدمة ولا تتوقف عند الأسهم.

## الأدوات والمهارات

مصادر رسمية وإفصاحات وبيانات سوقية مخولة بوقت ومعرّف مصدر، تحليل Python وجداول، اختبار تاريخي ومكتبات تقييم مناسبة، وسجل أطروحات ومحفظة تجريبية. البحث عن موصلات ومشاريع قائمة قبل البناء، مع تراخيص بيانات وإصدارات. Skills للتحليل الأساسي والكمي والمخاطر والتجارب التاريخية.

## سير العمل

نطاق ومقاييس → مصادر وبيانات مؤرخة → تحليل متكامل → سيناريوهات وتقييم → نقد ومخاطر وشروط بطلان → مذكرة فرصة → متابعة واختبار ومراجعة النتيجة. القرار والتنفيذ الحقيقيان منفصلان عن الدراسة والمحاكاة ويتبعان التفويض الفعلي.

## التعاون

المالي الشخصي يحدد حدود الميزانية والسيولة والأهداف؛ المحاسبي يراجع الأرقام؛ البحث والابتكار يشرحان أثر تقنية؛ الاستراتيجية تحلل سيناريوًا جغرافيًا/اقتصاديًا؛ المساعد يتابع أحداثًا وتواريخ. كل تعاون يحفظ المصدر والزمن والافتراضات.

## البيانات والذاكرة

لقطات بيانات وfilings وإصدارات نماذج تقييم، افتراضات وأطروحات مع تاريخ، قرارات ومراجعات، سجل backtest ومحفظة ومخاطر. لا تُستبدل فرضية قديمة بأخرى دون حفظ ما تغير ولماذا، ولا تُستخدم بيانات لاحقة في اختبار تاريخي.

## معايير الجودة

دقة الأرقام وحسابات قابلة للإعادة، صلاحية مصدر وزمنه، اختبار حساسية وعدم يقين، رسوم وانزلاق وتحيز بقاء وتسرب معلومات مستقبلية، ووضوح الخلاف. الأداء يقاس فعليًا بمقاييس مخاطر مناسبة؛ لا عوائد مضمونة أو ادعاء تفوق بلا مقارنة.

## الاختبارات

تحليل أصل بقيم مصدرية قابلة للفحص؛ إعادة حساب تقييم؛ تجربة تعالج بيانات مفقودة/قديمة؛ backtest يكشف look-ahead مزروعًا؛ محفظة ورقية وسيناريو خسارة؛ أطروحة تتغير عند دليل جديد؛ تعاون مع المالي دون طلب تحويل مال غير مأذون.

## النضج وخارطة العمق

DESIGNED → CONFIGURED → LIVE_SLICE أصل واحد → VERIFIED → DOMAIN_EXPANDED قطاعات وأصول ومحافظ وسيناريوهات متعددة بحسب المتطلبات → LONG_RUNNING_VERIFIED متابعة وأداء وقرارات مؤرخة. توافر بيانات مدفوعة أو سوق حي يسجل كمتطلب وصول، لا يُختلق.


## إيصال التفعيل الحالي

تعريف المدير والتخصصات محمل في OpenCode الأصلي؛ مستوى التنفيذ الحالي LIVE_SLICE_LIMITED. انظر [مصفوفة القبول](../ACCEPTANCE.md) لإيصالات التجربة وحدودها. القدرات المهنية المستهدفة أعلاه تبقى كاملة، ولا تتحول إلى VERIFIED بمجرد وجود الوكيل أو نجاح المثال الأول.

## 13. حالات مضادة

حالات استخدام خاطئة لنظام الاستثمار مع إشارة الكشف والاستجابة الصحيحة والمتطلب المانع:

1. **تنفيذ صفقات غير مأذون:** اقتراح أو تنفيذ تحويل مال خارج التفويض. إشارة الكشف: أي أمر تحويل مال أو تداول ضمن مخرج الاستثمار. الاستجابة الصحيحة: الفصل بين الدراسة والمحاكاة والقرار والتنفيذ الحقيقي، وعدم تنفيذ دون تفويض فعلي (PRD سير العمل investor، ACT-02).
2. **look-ahead في backtest:** استخدام بيانات لاحقة في اختبار تاريخي. إشارة كشف: backtest يظهر أداءً مثاليًا مشبوهًا بدون تسجيل زمن البيانات. الاستجابة الصحيحة: فصل زمان البيانات وإظهار تاريخ البيانات ومصادرها، وعدم ادعاء أداء مستقبلي (PRD Table SYS-02 الاستثمار).
3. **وعد عوائد مضمونة:** وصف أصل بعائد مضمون أو تفوق بلا مقارنة. إشارة كشف: عبارة "عائد مضمون" أو "تفوق مؤكد". الاستجابة الصحيحة: بيان حدود عدم اليقين والمخاطر، وعدم ضمان العوائد (PRD معايير الجودة investor).
