# نظام الابتكار وحل المعضلات

Primary: `dai-innovation`. الحالة: LIVE_PEER_LIMITED. **نظام مستقل متعاون مع البحث العلمي، وليس وظيفة تابعة له**. مرجع التكامل: [المعمارية](../TARGET_ARCHITECTURE.md).

## الأهداف

حل مسائل علمية وهندسية ورياضية وخوارزمية معقدة، وإنتاج اختراعات وحلول واختبارات قابلة للفحص. إدارة استكشاف طويل للفروض والمسارات الفاشلة والبدائل، وعدم الخلط بين فكرة مقترحة ونتيجة مثبتة.

## القدرات التفصيلية

- تأطير المعضلة وقيودها ومقاييس الحل وشروط الاستحالة أو النجاح.
- تقسيم المسألة إلى مشكلات وفرعيات وربط اعتمادياتها؛ مقارنة طرائق مستقلة قبل الدمج.
- بحث سوابق وحلول وقيود علمية وتقييم الجدة والمنافسة والمقايضات، مع فصل ادعاء الجدة عن نتيجته المحققة.
- توليد فرضيات وآليات ونماذج بديلة، نقل أفكار بين تخصصات عند وجود تفسير قابل للاختبار.
- تصميم خوارزميات وبرهان/أمثلة مضادة وتحليل تعقيد وتجارب مقارنة.
- هندسة بدائل ومعمارية نماذج أولية، محاكاة، تحليل حساسية وتحسين تحت قيود موارد.
- تصميم تجارب تفنيد وقياسات ومقارنتها بالbaseline؛ فصل علاقة رصدية عن سببية تجريبية.
- بناء artifact قابل للإعادة، وتقييم القيمة العلمية/الهندسية والقابلية للتنفيذ وما بقي مفتوحًا.

## الأدوار المتخصصة

مدير معضلة، مهندس صياغة، مولد فرضيات، رياضي، مصمم خوارزميات، مهندس مجال، مصمم تجارب، محلل محاكاة، باحث سوابق، ناقد تفنيد/أمثلة مضادة، مراجع تحقق، ومقيم جدوى. تتفرع أدوار الفيزياء والمواد والطاقة والبرمجيات وغيرها عند الحاجة الفعلية.

## الأدوات والمهارات

Python وحساب عددي/رمزي وتحسين ومحاكاة مجال؛ SymPy وSMT وLean4 أو غيرها حيث يناسب نوع الإثبات وتتوفر بيئة فعلية؛ مستودعات بيانات وسوابق/براءات عند توفرها؛ أدوات هندسية ومعيارية قائمة بعد التقييم. Tool يدير حسابًا أو تجربة ولا يصبح Runtime للوكلاء. Skills لاختبار فرضيات وتصميم مقارنة وتقييم الجدة وتوثيق فشل.

## سير العمل

عقد مشكلة → استرجاع سوابق وقيود → فروع فرضيات/طرائق → اختبار حسابي/محاكاة/تجربة → تفنيد وأمثلة مضادة → مقارنة بالbaseline → تحسين محدود السبب → مراجعة مستقلة → حل/منقوض/مفتوح/يحتاج تجربة → حفظ واستئناف. إعادة المحاولة تستند لمعلومة جديدة؛ لا تكرار توليد أفكار بلا مقيم.

## التعاون

يكلف البحث العلمي بالأدبيات والمنهج والتحقق من القيود؛ يتلقى منه المعضلات والفجوات دون نقل ملكيته. يتعاون مع التعليم لتعليم حل مثبت، والاستثمار/الإداري لتقييم جدوى منتج عند التفويض، والأمن السيبراني للتحقق الأمني في النطاق المخول. كل فرع يعود بأدلته وحدود صلاحية النتيجة.

## البيانات والذاكرة

شجرة فرضيات ومسارات وتجارب، بذور وتكوين وبيئة حسابية، مدخلات ونتائج خام، أسباب الفشل، proofs/counterexamples، مراجع سوابق وإصدارات artifacts. البحث الفاشل محفوظ لتجنب تكراره؛ ملخص المهمة يحيل إلى سجل التجارب لا يطمسه.

## معايير الجودة

تحقق الحل بالنسبة لعقده، تماسك الآلية، إعادة الإنتاج، صلاحية المحاكاة وافتراضاتها، اختبار ضد أمثلة مضادة، مقارنة أصلية عادلة، والجدة المدعومة. اكتشاف غير محقق يوصف كفرضية؛ برهان صوري لا يثبت سلامة نموذج فيزيائي لا يمثل الواقع.

## الاختبارات

مسألة رياضية/خوارزمية ذات جواب أو oracle معروف؛ كشف فرضية خاطئة بأمثلة مضادة؛ تجربة خوارزمية baseline مقابل بديل مع نتائج محفوظة؛ إعادة simulation من التكوين؛ تعاون حقيقي مع البحث؛ مهمة طويلة بفروع منقوضة ومفتوحة؛ توقف لقياس بشري ثم استئناف دون إعلان قياس لم يُجرَ.

## النضج وخارطة العمق

DESIGNED → CONFIGURED → LIVE_SLICE مسألة واحدة معلومة oracle → VERIFIED → DOMAIN_EXPANDED أنواع مسائل متعددة وتخصصات وتجارب وجدة ومقايضات → LONG_RUNNING_VERIFIED برامج ابتكار طويلة. موارد المختبر أو الحوسبة الكبيرة متطلبات تشغيل مستقلة، لا سبب لاختزال المواصفة إلى سؤال بسيط.


## إيصال التفعيل الحالي

تعريف المدير والتخصصات محمل في OpenCode الأصلي؛ مستوى التنفيذ الحالي LIVE_PEER_LIMITED. انظر [مصفوفة القبول](../ACCEPTANCE.md) لإيصالات التجربة وحدودها. القدرات المهنية المستهدفة أعلاه تبقى كاملة، ولا تتحول إلى VERIFIED بمجرد وجود الوكيل أو نجاح المثال الأول.

## 13. حالات مضادة

حالات استخدام خاطئة لنظام الابتكار مع إشارة الكشف والاستجابة الصحيحة والمتطلب المانع:

1. **إثبات رياضي كبديل عن 경험 فيزيائي:** اعتبار البرهان الصوري دليلًا على سلامة نموذج فيزيائي لا يمثل الواقع. إشارة الكشف: استشهاد ببرهان رمزي كدليل فيزيائي. الاستجابة الصحيحة: فصل أنواع الإثبات حسب الفرع، وقصر الاستدلال الفيزيائي على تجربة أو محاكاة ممثلة (PRD جدول الابتكار، فرق المنهج).
2. **إClaim بالجدة العالمية:** وصف فكرة جديدة بأنها جدة عالمية مطلقة من بحث محدود. إشارة الكشف: عبارة "جدة عالمية" دون نطاق محدود. الاستجابة الصحيحة: تحديد أصل وجدة محدودة النطاق، وعدم المبالغة في claim (PRD جدول الابتكار، مخرجات ودليل جودة).
3. **تكرار توليد أفكار بلا مقيم:** إنتاج أفكار متتالية دون مقيم أو تفنيد. إشارة الكشف: أكثر من دورة توليد أفكار دون سجل إخفاقات أو مقيم. الاستجابة الصحيحة: إرفاق ناقد تفنيد/أمثلة مضادة بكل دورة، والتوقف عند عدم وجود مقيم (PRD SER العمل، لا تكرار توليد أفكار بلا مقيم).
