# نظام التحقيق والاستقصاء

Primary: `dai-investigation`. الحالة: CONFIGURED منذ البداية؛ التفعيل على دفعة لاحقة. مرجع التكامل: [المعمارية](../TARGET_ARCHITECTURE.md).

## الأهداف

إدارة قضية/سؤال استقصائي من التأطير إلى جمع وتحليل وتفنيد ومراجعة وإخراج نتيجة محددة النطاق، مع أثر مصدر لكل ادعاء وكيان وعلاقة. دعم قضايا كبيرة ومتعددة المصادر وفروع تحقيق طويلة، في نطاق البيانات المخولة.

## القدرات التفصيلية

- تأطير قضية ومعايير نجاح وحدود وصول، تفكيك أسئلة وفرضيات متنافسة وخطة مصادر.
- OSINT ومصادر عامة/مرخصة وأرشيف وسجلات ووثائق وبيانات مالية/شركات عند توفرها.
- استرجاع وثائق وملاحق وصور/فيديو ونصوص وmetadata، مع حدود دقة OCR/ASR والتحقق المرئي الفعلي.
- استخراج كيانات وربطها مع تحليل غموض وتشابه أسماء وعدم الجزم بهوية بلا سند.
- خط زمني وتحليل أحداث وعلاقات وشبكات، فصل العلاقة المثبتة عن الاستنتاج المحتمل.
- تحليل خرائط وجغرافيا وصور أقمار صناعية عند الحاجة والقدرة على الوصول، مع عدم يقين موقع/زمن.
- مقارنة مصادر وتقييم موثوقية وتناقضات وبحث دليل نفي وفجوات؛ استقلال مصادر لا عدد الروابط.
- ملف قضية وتقرير وأدلة قابلة للتدقيق ومراجعة وتحديث عند معلومات جديدة.

## الأدوار المتخصصة

مخطط قضية، باحث مصادر/أرشيف، محلل وثائق، محلل كيانات، محلل زمن، محلل مالي/شركات، محلل وسائط، متخصص جغرافي، ناقد فرضيات، مراجع مصدر، ومحرر تقرير. تخصصات إضافية حسب القضية، وليس عددًا ثابتًا.

## الأدوات والمهارات

بحث ومتصفح وأرشيف وPDF/OCR وجداول، بيانات عامة/مرخصة، GIS وأدوات وسائط وتحليل علاقات قائمة بعد فحص الترخيص والأمن والتوافق. Skills لتقييم مصدر وسلسلة أصل وتحليل زمن وفرضيات. أداة غير متاحة تظهر كفجوة، لا تحليل وهمي لصورة أو موقع.

## سير العمل

عقد قضية → خطة وفرضيات → جمع بأصل محفوظ → تحليل كيانات/زمن/جغرافيا → مقارنة وتفنيد → مراجعة تناقضات وفجوات → استنتاج مع درجات دعم → تقرير → مراقبة/إعادة فتح. الفرضية المنقوضة تبقى في السجل.

## التعاون

يكلف البحث العلمي بمسألة تقنية، المستثمر بتحليل إفصاحات، الاستراتيجية بتفسير سيناريو جغرافي، والسيبراني بفحص دليل رقمي ضمن تفويضه. مشاركة البيانات مقتصرة على نطاق القضية؛ لا وصول تلقائي لملف قانوني أو شخصي من نظام آخر.

## البيانات والذاكرة

مجلد قضية ومصادر أصلية وبصمات ووقت جمع وحقوق الوصول، سجل claims/entities/events، ثقة وعلاقات مع دليلها، ملاحظات تناقض وحالات فرضيات وطلبات بشرية. أدلة حساسة لها قيود قراءة/تصدير، والملخص لا يحل محل الأصل.

## معايير الجودة

provenance لكل ادعاء، فصل الوقائع والتصريحات والتحليل والاستنتاج والمجهول، صحة هوية وزمن، فحص الأدلة المضادة، عدم تضخيم المصادر المكررة، ووضوح النطاق والخصوصية. لا رصد خفي أو استنتاج هوية يقيني من تشابه أسماء.

## الاختبارات

قضية عامة صغيرة بجدول أدلة؛ إشاعة معاد تدويرها من عدة روابط تُكشف كمصدر واحد؛ كيانان بالاسم نفسه لا يندمجان؛ تعارض تاريخ؛ فرضية منقوضة؛ تحليل وسائط يعلن غياب التحقق المرئي؛ استئناف قضية وفحص نسخة مصدر جديدة؛ تعاون بين نظامين بصلاحية صحيحة وسلبية.

## النضج وخارطة العمق

DESIGNED → CONFIGURED → LIVE_SLICE قضية عامة → VERIFIED → DOMAIN_EXPANDED قضايا متعددة المصادر ومجالات ووثائق/وسائط/GIS بحسب المتطلبات → LONG_RUNNING_VERIFIED ملفات ممتدة وتحديثات ومراجعات. كل قدرة متخصصة لها قبول مستقل؛ لا يثبت اختبار الويب عمل تحليل الأقمار الصناعية.


## إيصال التفعيل الحالي

تعريف المدير والتخصصات محمل في OpenCode الأصلي؛ مستوى التنفيذ الحالي CONFIGURED. انظر [مصفوفة القبول](../ACCEPTANCE.md) لإيصالات التجربة وحدودها. القدرات المهنية المستهدفة أعلاه تبقى كاملة، ولا تتحول إلى VERIFIED بمجرد وجود الوكيل أو نجاح المثال الأول.
