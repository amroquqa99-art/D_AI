# D_AI — Domain Systems Contracts

## 1. نظام التحقيق | Investigation System

### الهدف
نظام للتحقيق والبحث الاستقصائي متعدد المصادر، مخصص للوصول إلى صورة دقيقة وقابلة للتدقيق حول أشخاص أو كيانات أو أحداث أو بيانات أو قضايا.

### أسلوب العمل
- فهم القضية وصياغة نطاقها.
- بناء Hypothesis Tree وأسئلة فرعية.
- Entity resolution وربط الأشخاص والكيانات والأماكن والأحداث.
- البحث التكراري متعدد المسارات.
- تحليل زمني ومكاني.
- OSINT وGEOINT والمستندات والميديا والسجلات وقواعد البيانات والمصادر المصرح بها.
- اكتشاف التناقضات والتضليل والإشارات الضعيفة.
- اختبار التفسيرات البديلة والأدلة المضادة.
- سد الفجوات عبر إعادة البحث أو طلب بيانات إضافية.

### المخرجات
ملف تحقيق يحتوي الأدلة، المصادر، الخط الزمني، خرائط العلاقات، الفرضيات، الاستنتاجات، درجات الثقة، الفجوات، وما يحتاج تحققًا إضافيًا.

## 2. نظام البحث العلمي | Scientific Research System

### الهدف
إنتاج معرفة علمية جديدة قابلة للاختبار وإعادة الإنتاج، وليس تلخيص الدراسات السابقة فقط.

### مدخلات الباحث
- السؤال الرئيسي.
- الفرضيات.
- الأسئلة الفرعية.
- ملاحظات الباحث.
- تجاربه السابقة.
- بياناته.
- كتبه وملفاته ومراجعه.
- الموارد المتاحة.
- الميزانية.
- الوقت والمعدات والقيود.

### مصادر المعرفة
أبحاث محكمة، رسائل ماجستير ودكتوراه، كتب، محاضرات جامعية، مساقات، مستودعات أكاديمية، براءات، بيانات خام، تجارب منشورة، تقارير، توثيقات، datasets، وأي أدلة علمية موثوقة متاحة قانونيًا.

### أسلوب العمل
- Literature/Research Graph.
- تحديد gaps والتناقضات.
- الاستقراء والاستنباط.
- التحليل الإحصائي.
- النمذجة الرياضية والحاسوبية.
- تصميم التجارب.
- محاكاة.
- فرضيات متنافسة.
- Independent verification.
- نقد المنهجية والنتائج.

### Human-in-the-loop العلمي
عند الحاجة لتجربة أو استطلاع أو مقابلة أو قياس أو عينة أو ملف، ينشئ النظام مهمة للباحث تتضمن المطلوب والمنهجية والمعايير. ينتقل المسار إلى WAITING_FOR_HUMAN ويستمر بعد عودة النتائج.

### المخرجات
بحث أو تقرير علمي قابل لإعادة الإنتاج مع المنهجية والبيانات والفرضيات والنتائج والحدود والمراجع ومستوى الثقة والإسهام المعرفي.

## 3. نظام المستثمر | Investor System

### الهدف
تحليل الشركات والأسواق والأصول للوصول إلى قرارات استثمارية مدروسة قصيرة وطويلة الأجل، مع التركيز على القيمة والمخاطر وعدم اليقين.

### التحليل
- القوائم المالية.
- التدفقات النقدية.
- الأرباح والديون.
- الإدارة والحوكمة.
- الميزة التنافسية.
- الاقتصاد الكلي.
- أسعار الفائدة والتضخم.
- الأخبار والأحداث.
- هيكل الملكية وأصحاب التأثير.
- السيولة والمزاج السوقي.
- التحليل الكمي والإحصائي.
- السيناريوهات والحساسية.
- backtesting مضبوط ضد leakage.

### أطروحة الاستثمار
لكل فرصة يبني النظام Thesis تحتوي:
- سبب الفرصة.
- الأدلة الداعمة.
- الأدلة المضادة.
- القيمة العادلة المقدرة.
- السيناريو المتفائل/الأساسي/المتشائم.
- المحفزات.
- المخاطر.
- شروط إلغاء الفرضية.
- أثرها على المحفظة.

### المخرجات
تقارير استثمارية قابلة للتدقيق، Watchlists، سيناريوهات، Portfolio analysis، وتنبيهات عند تغير الفرضية الاستثمارية.

## 4. نظام الأمن السيبراني | Cybersecurity System

### الهدف
مساعدة الأفراد والمؤسسات والجهات المخولة في حماية الأنظمة، اكتشاف الثغرات، تحليل الحوادث، التحقيق الرقمي، واختبار البيئات المصرح بها.

### الاستخدام الشخصي والمؤسسي
- Asset discovery داخل النطاق المصرح.
- Threat modeling.
- مراجعة كود وإعدادات.
- اكتشاف misconfiguration والأسرار المكشوفة.
- تحليل الشبكات والسجلات.
- vulnerability analysis.
- malware analysis في بيئات معزولة.
- hardening.
- remediation verification.
- Red/Blue team في نطاقات مختبرية أو مصرح بها.

### الاستخدام التحقيقي للجهات المخولة
- تحليل الأدلة الرقمية.
- استعادة وربط artifacts.
- timeline reconstruction.
- device/system forensics ضمن الصلاحية.
- ربط النتائج مع نظام التحقيق والعمليات والاستخبارات.

### الاستخدام الحكومي/الأمني
يدعم تحليل التهديدات السيبرانية، الشبكات والبرمجيات والبنية التقنية المعادية، وبناء صورة تقنية تساعد في الفهم والدفاع واتخاذ القرار داخل نطاق التفويض.

أي إجراء مؤثر على أنظمة خارجية حقيقية يجب أن يكون محكومًا بتفويض وصلاحية ونطاق وتدقيق وموافقة مناسبة. لا تكون الصلاحيات مجرد نص في Prompt.

### المخرجات
Findings قابلة لإعادة الفحص، severity، evidence، affected assets، remediation، retest results، audit trail.

## 5. نظام العمليات والاستخبارات | Operations & Intelligence System

### الهدف
تحويل البيانات القادمة من الميدان والتحقيق والأمن السيبراني والمصادر المختلفة إلى صورة عملياتية مترابطة تساعد الشرطة والجهات الأمنية والعسكرية على الفهم والتحليل واتخاذ القرار.

### الاستخدام الشرطي
- ملفات قضايا مترابطة.
- تحليل الشبكات الإجرامية.
- ربط الأشخاص والأجهزة والحسابات والمركبات والمواقع والمعاملات والأحداث.
- timeline وتحليل أنماط.
- تحديد فجوات التحقيق.
- دمج الأدلة الرقمية والميدانية.
- قياس الثقة في كل رابط.

### الاستخدام العسكري والأمني
- تحليل البيئة العملياتية.
- تحليل التكتيكات والأنماط والقدرات.
- خرائط الكيانات والوحدات والبنية التحتية.
- تحليل سلوك الخصم والتغيرات عبر الزمن.
- بناء سيناريوهات متعددة.
- تقدير مستوى الانكشاف والمعلومات المحتمل أن يمتلكها الطرف الآخر.

### الاستخبارات المضادة والدفاع النشط
يتعامل النظام مع وسائل المراقبة والاستطلاع والتتبع والحساسات والمنصات غير المأهولة والبنى الاتصالية كمصادر تهديد ومعلومات في آن واحد.

يقيم:
- ما الذي قد تجمعه الوسيلة.
- ما الذي يبدو أن الخصم يبحث عنه.
- نمط التكرار والمسار والتوقيت.
- القيمة الاستخباراتية مقابل الخطر.
- خيارات الاحتواء أو المراقبة أو الحماية أو الخداع المصرح به.

لا يتحول النظام إلى سلطة مستقلة لاتخاذ إجراء ميداني أو تقني عالي الأثر. القرارات الحساسة تخضع لسلسلة قيادة وتفويض واضحة.

### التكامل
الأمن السيبراني يفسر الجانب التقني، التحقيق يثبت ويربط الأدلة، والعمليات والاستخبارات يحول النتائج إلى معنى عملياتي وسيناريوهات.

### المخرجات
Operational picture، entity/network maps، timelines، hypotheses، risk/uncertainty، intelligence gaps، options analysis، periodic updates.

## 6. نظام الابتكار والاكتشاف | Innovation & Discovery System

### الهدف
حل المعضلات العلمية والتقنية شديدة التعقيد، توليد فرضيات ونظريات واختراعات وحلول جديدة، وربط تخصصات متعددة لإنتاج معرفة جديدة.

### بنية العمل
يشغل عدة فرق/وكلاء تخصصيين مثل:
- رياضيات.
- فيزياء.
- أحياء/طب.
- هندسة.
- علوم حاسوب.
- محاكاة.
- تجارب.
- نقد وعدائية علمية.
- Prior art / novelty.

### أسلوب الحل
- First principles.
- Reframing للمشكلة.
- فرضيات متنافسة.
- reasoning alternatives.
- نمذجة ومحاكاة.
- برهان أو اختبار عددي حيث يناسب.
- counterexample search.
- failure memory.
- cross-domain analogy.
- novelty checking.

### دورة الاكتشاف
1. تعريف المشكلة.
2. فصل المعروف عن المجهول.
3. كشف الافتراضات الضمنية.
4. توليد عدة مسارات مستقلة.
5. دمج أفكار عبر التخصصات.
6. نقد ومحاولة دحض.
7. محاكاة/اختبار.
8. تصنيف النتيجة.
9. تحويل النتائج الواعدة للبحث العلمي للتحقق الرسمي.

### حالات النتيجة
VERIFIED / REFUTED / OPEN / NEEDS_EXPERIMENT / NEEDS_DATA.

### المخرجات
فرضيات، نماذج، خوارزميات، نظريات قابلة للاختبار، تصميمات هندسية، مسارات بحث، بروتوكولات تجريب، أفكار براءات، وخرائط علاقات معرفية.

---

## 7. قواعد التكامل بين الأنظمة
- Investigation ↔ Scientific Research: تحقق مصادر وأدلة علمية.
- Investigation ↔ Investor: تحقيق مالي وشركات وكيانات.
- Cybersecurity ↔ Operations & Intelligence: من الأدلة التقنية إلى الصورة العملياتية.
- Innovation ↔ Scientific Research: من الفكرة إلى تجربة قابلة للتحقق.
- Investor ↔ Innovation: تقدير الجدوى الاقتصادية للتقنيات.
- جميع الأنظمة ↔ Local Intelligence Core: learning/evaluation/routing ضمن سياسات البيانات.

كل Cross-system call يسجل origin, target, tool, permission, evidence, cost, result.
