# دمج موارد AgenticSkills — 2026-11-09

الحالة: **دفعة عاملة محدودة ضمن 0.1، وليست قبول النظام كاملًا**.

## ما دُمج

فُحصت الأقسام الخمسة Skills وMCP Servers وWorkflows وTools وLearn، ثم روجعت مصادر مختارة أصلية. لم تُنسخ مستودعات أو تُثبت منظومة وكلاء أخرى.

| القسم | الاختيار | الحالة الفعلية |
|---|---|---|
| Skills | systematic-debugging، verification-before-completion، using-git-worktrees | تكييفات محلية قصيرة بمراجع commits وترخيص MIT |
| MCP | Context7، MarkItDown | أدلة تشغيل/تراجع اختيارية؛ ليست خوادم مفعلة تلقائيًا |

المراجع والبصمات: `resources/agenticskills/provenance.json`، والفهرس: `resources/agenticskills/catalog.json`. تكييف Superpowers محدود بالمصادر المثبتة؛ نص الإسناد والترخيص محفوظ. ترخيص مستودع لا يثبت ترخيص كل تبعية أو سلامة نشر خدمة بعيدة.

## الاستخدام وإدارة السياق

- الأمر `/dai-resources` والمهارة `dai-resource-discovery` يقودان إلى بحث محدد.
- `dai_resource_search`: بيانات تعريفية فقط، حد 8 نتائج، واستجابة JSON حتى 6000 بايت UTF-8. لا شبكة ولا تفعيل.
- `dai_resource_read`: معرف من الفهرس، لا مسار عشوائي؛ محتوى الصفحة 256–4000 بايت، والاستجابة كلها حتى 6000 بايت شاملة JSON escaping؛ متابعة بـ`next_offset` (إزاحة محارف JavaScript، لا إزاحة بايتات).
- فُحصت العربية وemoji وإعادة تركيب الصفحات، ومنع traversal والروابط الخارجة والملفات فوق 64 KiB.
- لا ينقل الراوتر آخر ست رسائل للأب تلقائيًا. عقد العامل يحمل الهدف ومراجع المدخلات؛ يجب أن يكون التكليف مكتفيًا بتفاصيله.
- ملف المشروع `opencode.jsonc` يفعّل الضغط التلقائي، ويحتفظ بذيل 8000 توكن، ويضبط `buffer: 12000` عددًا صحيحًا كما يقبله OpenCode 2.2.5، ويحد مخرجات الأدوات إلى 200 سطر/12000 بايت. التوثيق الأحدث يعرض نسبة مئوية؛ أظهر فحص المضيف أن إصدار الاختبار يسقط تلك الصيغة، ولذلك صُححت إلى القيمة العددية المدعومة. المثبت يضيف الافتراضيات فقط عند غياب إعداداتها، ولا يستبدل اختيار المالك.
- هذه حدود بايتات وسياسة compaction، وليست قياسًا لتوفير توكنات أو ضمانًا لاستحالة overflow. إجمالي تعليمات المضيف والأدوات ومخرجات النموذج يظل مؤثرًا.

## الإصلاحات المرتبطة

1. `dai-lead` أصبح `primary` في المصدر والتثبيت؛ `/os` يختاره، مع بقاء `dai-os` مدخلًا متاحًا.
2. للقائد سلطة الاختيار الدلالي بدل التفويض المسبق بكلمة مفتاحية، مع احترام منع التفويض.
3. أدوات الراوتر والموارد تُعرض مباشرة عبر `codemode:false`؛ لا تحتاج صلاحية `execute` التي يمنعها القائد.
4. فحص variants يتعامل مع الحقول الناقصة/الأشكال الأصلية بدل الانهيار على `.includes`.
5. المثبت يكتب V2 `mcp.servers.dai` و`disabled`، ويحترم JSON/JSONC وإعدادات المستخدم، ولا يحذف markers داخل النصوص.
6. أخطاء التفويض في MCP تستخدم `ToolError` بدل إعادة dict في أداة معلنة list مما كان يسبب خطأ schema مضللًا.
7. الرجوع عن نسخ أدلة المهارات يتطلب بصمة محتويات؛ يبقي النسخ المعدلة/غير مثبتة الملكية والنسخ الاحتياطية السابقة.
8. الحالة الجديدة للراوتر على نظام Linux خارج مستودع المصدر؛ التثبيت السابق يحتفظ بسجلاته وأقفاله ولا يتجاهل الأعمال الغامضة. سجل FAT قديم يحتاج ترحيلًا صريحًا غير متصل.

## التحقق المنفذ وحدوده

الاختبارات وإيصالات التشغيل في `docs/checkpoints/2026-11-09-agenticskills.md`.

- شُغّل OpenCode v2.2.5 مع Beam المجاني في جلسات اختبار جديدة؛ لم يُغير نموذج جلسة المالك.
- نجح ظهور/تنفيذ البحث والقراءة، ثم إنشاء عامل native له job وchild وmodel وreceipt حقيقية. اختبار العامل no-file صغير وليس تقييمًا للقدرة المهنية.
- نجح إنشاء مشروع ومهمة وقراءتها عبر MCP ببيانات اختبار منفصلة. الجلسة الحالية بهوية `build` ترفض أدوات بيانات D_AI؛ لم تُخترع هوية أو يُتجاوز الرفض.
- نجح اتصال Context7 واستدعاء `resolve-library-id` بطلب عام بعد محاولة اتصال فاشلة. لم يُرسل كود خاص أو مفتاح ولم يُفعل الخادم عالميًا. إعادة التشغيل الاختيارية: `python scripts/probe_context7.py --allow-network` داخل بيئة MCP المهيأة.
- نُسخت ملفات runtime المحددة إلى التثبيت المحلي بعد فحص اختلافاته مع حفظ نسخة رجوع. لم تُستبدل تعديلات المثبت السابقة في التثبيت، أو النماذج أو المزودات أو بيانات المالك.
- أُزيل تسجيل الراوتر المحلي المكرر من إعداد المشروع القديم فقط، بعد حفظ الأصل؛ لم تُرحل قاعدة MCP القديمة أو تُعامل كبديل مكافئ للمخزن المشفر.
