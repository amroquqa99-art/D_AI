# المرجع — مهمة المقارنة الثنائية (A/B)

هذه المهمة **ثابتة**. تُمرَّر حرفياً إلى الذراعين (baseline وsystem) بلا أي تعديل
بينهما. أي تغيير في نصها يُبطل نتيجة المقارنة.

> **لماذا نصّ واحد؟** لأن المقارنة تُقيس أثر النظام على **نفس** العمل، لا
> أثر سؤالين مختلفين. لذلك: النص نفسه، النموذج نفسه، مساحة العمل نفسها،
> والميزانية نفسها.

---

## النص المُمرَّر إلى الذراعين (كما هو، بلا تعديل)

````text
ابحث عن ثلاث فرص بحثية في تقاطع الطب والذكاء الاصطناعي، تحديداً أين يمكن لنماذج التوقّع أو التصنيف على بيانات المرضى أن تنتج معرفة سريرية
جديدة. لكل فكرة قدّم:

1. المشكلة والفجوة البحثية، مع مصدر أصلي يدعمها (رابط DOI أو رابط مباشر).
2. سؤال أو فرضية قابلة للاختبار.
3. أقرب العمل الموجود، وما الفارق الذي يجعل الفكرة جديدة.
4. المنهج المقترح ومصادر البيانات المتاحة.
5. معيار قبول واضح، وخطة تقييم بميزانية قابلة للتقدير.
6. ما الذي قد يُبطل الفكرة.

قيّد الأدبيات بعام 2019–2026، واذكر بوضوح أي نقطة لم تستطع التحقق منها.
````

## قواعد ثابتة للطرفين

| القاعدة | القيمة |
|---|---|
| النموذج | نفس معرّف `provider/model` بالضبط في الذراعين |
| مساحة العمل | مجلد فارغ جديد لكل ذراع، بالمحتوى نفسه |
| المهارات | **لا مهارة خارجية في أي ذراع**. الذراع A بلا مهارات إطلاقاً، والذراع B بمهارات D_AI وحدها |
| الأدوات | الذراع A: أدوات المضيف الافتراضية فقط. الذراع B: نفس الأدوات + خادم MCP الخاص بـ D_AI |
| الميزانية | سقف زمني متطابق (يُحدَّد عند التشغيل) |
| الجلسات | جلسة جديدة نظيفة لكل ذراع، بلا `--continue` |
| الترتيب | يُنفَّذ الذراع A أولاً ثم B (ويمكن عكسه بـ `--reverse` لاختبار أثر الترتيب) |

## ما الذي لا يُقاس

- **طول الإجابة.** طول النص ليس جودة، والامتياز في الاختصار الدقيق.
- **عدد الأدوات المستخدمة.** نظام يعطي إجابة أسرع قد يكون أفضل، أو أسوأ.
- **انطباع المراجع.** يُقاس بالمعايير المسمّاة في [RUBRIC.md](RUBRIC.md) وبفواصل
  مُعلنة، لا انطباعاً حراً.

## ما الذي يُقاس

1. **دعم المصدر** — هل كل ادعاء مادي مرتبط بمصدر يمكن التحقق منه؟
2. **سلامة الاستنتاج** — هل الفصل بين الثابت والمفترض والمجهول صريح؟
3. **قابلية الاختبار** — هل لكل فكرة معيار قبول وميزانية قابلة للتقدير؟
4. **الجدة المُقنَّنة** — هل الفارق عن أقرب العمل محدد لا مُدَّعى؟
5. **قابلية الاستئناف** — هل يستطيع غير الكاتب متابعة العمل من المخرجات؟
6. **تكلفة العمل** — الوقت والتوكنات والأدوات المستخدمة.

## بروتوكول التنفيذ

```bash
# 1) تشغيل الذراعين وجمع الأدلة
python scripts/ab_compare.py --task docs/evaluation/REFERENCE_TASK_SCI.md \
    --model opencode/<model-id> --out docs/evaluation/runs/<stamp>

# 2) تقييم أعمى من مراجع مستقل
python scripts/ab_score.py --run docs/evaluation/runs/<stamp>

# 3) قراءة النتيجة
cat docs/evaluation/runs/<stamp>/COMPARISON.md
```

المراجع في الخطوة 2 **لا يعرف** أي ذراع هو الأساسي وأيهما هو النظام: تُسلَّم
له المخرجات مسمّاة `A` و`B` بترتيب عشوائي، وتُفكّ الأسماء بعد التسجيل.
