# ADR 0004 — 原生模块化运行时与独立推理、搜索服务

[English](0004-local-inference-and-open-source-reuse.md) | 中文

- 状态：在已批准的原生插件架构内接受
- 日期：2026-10-07

## 决策

保留原生 Harness/Cordis 模块化单体并继续 ADR 0002 (`0002-runtime-decomposition.md`) 的拆分。推理和搜索置于可独立配置的外部服务。复用原生提供方、subagent、token meter、compaction、持久化和作用域工具 API。本地决策辅助是显式启用插件，独立于领域变更及训练治理。

## 理由

当前运行时已拥有持久 Session、独立 Agent、投影、有 fence 的任务执行及审批。没有更符合需求的证据就替换它，会丢弃已验证行为。进程本地调度和大型服务组合文件仍需改进；这是有用基础，不证明生产就绪或分布式运行。小模型受益于简短独立上下文和有限工具目录；领域质量可独立于传输评估。

VM 或持久容器可以托管同一 profile，远程推理可降低桌面负担。无服务器请求生命周期不能为长期 agent 提供持久运行环境。多主机 worker、冷 Session 激活和分布式调度需要明确设计与故障测试，不能只把当前进程放到云上。

## 后果与验证

推理位置、端点认证、许可证和文件哈希由部署拥有。建议未经验证且不扩大权限。压缩后原始来源/证据仍是权威事实。模型输入/输出沿用原生子 Session 日志，不新增持久化事件代际。分别测试真实 Loader 组合、作用域隔离、错误输出、编造引用、资源限制、取消、释放和真实推理。不要依据一个成功输出或仅 fixture 测试晋升小模型。
